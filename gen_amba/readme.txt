==========================================================
AMBA RTL Generator Tool (Professional Edition)
==========================================================

1. 项目目录结构
----------------------------------------------------------
gen_amba/
├── cfg/
│   ├── template.txt           # 默认协议模板
│   └── template_mini.txt      # 可选的其他协议模板
├── src/
│   └── gen_amba.py            # 核心脚本 (支持 Python3 自动运行)
├── out/                       # 自动创建的输出目录
│   └── amba_top.sv            # 生成的 SystemVerilog 顶层文件
└── config.json                # 全局配置文件 (指定模板与实例)

2. 核心功能特性
----------------------------------------------------------
- 多模板切换：通过 config.json 中的 "template_file" 字段指定加载 cfg/ 下的任意模板。
- 信号类型保持：支持模板中 input/output 后的 logic, wire, reg 等各种声明类型。
- 智能参数解析：
    * 若前台指定参数值 (params)，自动计算并替换为具体数字 (如 [31:0])。
    * 若前台未指定参数，则原样透传参数名 (如 [ADDR_WIDTH-1:0])。
- 动态自动对齐：生成的 .sv 文件将根据方向、声明类型、位宽长度自动计算缩进对齐。
- 主从自动翻转：根据 mode (master/slave) 自动对调 input 和 output 方向。
- 协议级去重：GLOBAL: 标记的信号 (如 aclk) 在同一协议实例化多次时，仅产生一次。

3. 配置规范
----------------------------------------------------------
- template_file (可选): 指定模板文件名，不填则默认使用 template.txt。
- protocol: 必须与模板文件中 [label] 括号内的名称严格匹配。
- params: 字典格式，键名需与模板中的大写参数名一致。

4. 运行环境与执行
----------------------------------------------------------
- 环境要求：Python 3.6+
- 运行权限 (Linux/macOS):
    chmod +x src/gen_amba.py
- 执行命令:
    ./src/gen_amba.py
    (或 python3 src/gen_amba.py)

生成的代码将自动存放在根目录下的 out/amba_top.sv 中。
