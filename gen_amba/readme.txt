==========================================================
AMBA RTL Generator Tool
==========================================================

1. 目录结构
----------------------------------------------------------
gen_amba/
├── cfg/
│   └── template.txt      # 协议 RTL 代码块模板
├── src/
│   └── gen_amba.py       # 核心逻辑脚本
├── config.json           # 实例名称与参数配置
└── amba_top.v            # 自动生成的 RTL 文件

2. 使用说明
----------------------------------------------------------
- 模板配置 (cfg/template.txt):
  * 使用 [protocol_name] 定义协议块。
  * 使用 GLOBAL: 标记协议共用的时钟/复位信号。
  * 信号位宽支持大写参数 (如 [ADDR_WIDTH-1:0])。

- 前台配置 (config.json):
  * prefix: 接口信号的前缀。
  * protocol: 匹配模板中的协议块名称。
  * mode: 支持 "master" 或 "slave"，脚本自动翻转输入输出方向。
  * params: 定义位宽参数。若此处未定义某个参数，RTL 将透传保留参数名。

3. 运行方法
----------------------------------------------------------
在 src 目录下执行：
python gen_amba.py

执行完成后，生成的 amba_top.v 将出现在项目根目录下。

4. 自动处理规则
----------------------------------------------------------
- 信号名转换：所有生成的信号名均自动转换为小写。
- 接口去重：同一协议的 GLOBAL 信号在模块中仅出现一次。
- 格式化：自动处理端口列表末尾的逗号，并删除接口间的冗余空行。
