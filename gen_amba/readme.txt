==========================================================
AMBA RTL Generator Tool (Industrial Grade)
==========================================================

1. 项目目录结构
----------------------------------------------------------
gen_amba/
├── cfg/
│   ├── template.txt           # 协议模板 (支持角色定义 [label:role])
│   └── axi_minimal.txt        # 其他可选协议模板
├── src/
│   └── gen_amba.py            # 核心生成脚本 (支持 Python3 直接运行)
├── out/                       # 自动创建的输出目录
│   └── amba_top.sv            # 生成的 SystemVerilog 顶层文件
└── config.json                # 全局配置文件 (前台输入)

2. 核心功能特性
----------------------------------------------------------
- 现代路径管理：基于 pathlib 实现，可在任何路径下执行脚本，自动定位根目录。
- 信号类型全支持：完美保留并对齐模板中的 logic, wire, reg 等各种声明类型。
- 像素级风格还原：
    * 完美兼容 Verilog 逗号分割格式。
    * 信号名与逗号之间的“空格距离”以后台模板中的实际间距为准进行还原。
- 智能模式切换：
    * 常规模式：master (保持模板方向) 或 slave (整体镜像翻转)。
    * 交替模式：m_s_alt (主->从->主...) 或 s_m_alt (从->主->从...)。
    * 配合 prefix 数组，可实现一组配置自动生成非对称排列的复杂接口。
- 后台角色定义 (Role-based)：
    * 模板头支持 [protocol:M] 或 [protocol:S] 显式标注。
    * 脚本根据 (当前实例模式 + 后台信号角色) 自动判断是否需要翻转方向。
- 动态参数引擎：
    * 自动计算数学表达式（如 [DATA_WIDTH/8-1:0]）。
    * 前台未定义的参数将作为 Verilog Parameter 原样透传。

3. 配置指南 (config.json)
----------------------------------------------------------
- template_file: (可选) 指定 cfg/ 下的模板文件，默认为 template.txt。
- module_name: 指定生成的 SV 模块名称。
- instances: 实例列表
    * prefix: 字符串 (如 "m0") 或 数组 (如 ["s0", "s1", "m0"])。
    * protocol: 匹配模板中的 [label]。
    * mode: master, slave, m_s_alt, s_m_alt。
    * params: 位宽等参数字典。

4. 运行说明
----------------------------------------------------------
- 环境要求：Python 3.6+
- 执行权限 (Linux/macOS):
    chmod +x src/gen_amba.py
- 运行命令:
    ./src/gen_amba.py

5. 输出对齐规范
----------------------------------------------------------
生成的 .sv 文件遵循以下对齐顺序：
[方向] {6位对齐} [类型] {动态对齐} [位宽] {动态对齐} [信号名] [后台空格] [逗号]
